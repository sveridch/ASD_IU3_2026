## Условные обозначения

- **Вход:** описание входных данных
- **Выход:** описание ожидаемого результата
- **Ограничения:** ограничения на размер и значения данных
- **Сложность:** базовая / средняя / высокая — ориентир для self-check

Во всех задачах, если не указано иное:
- Массив — целочисленный, индексация с нуля.
- Размер массива \(n\) удовлетворяет (1 < n < 10^5), если не оговорено отдельно.
- Ввод данных и вывод результата осуществляются через стандартные потоки ввода-вывода (клавиатура, файлы и тд).
- Требуемая асимптотическая сложность указана там, где это критично; в остальных случаях достаточно \(O(n)\) или \(O(n \log n)\).

## 1. Линейный поиск и фильтрация (задачи 1–12)

### Задача 1. Максимум и минимум

**Вход:** массив из \(n\) целых чисел.  
**Выход:** минимальный и максимальный элементы массива.  
**Ограничения:** \(1 < n < 10^5\).  
**Сложность:** базовая

### Задача 2. Индекс первого вхождения

**Вход:** массив из \(n\) целых чисел и число \(x\).  
**Выход:** индекс первого элемента, равного \(x\). Если такого нет — вывести `-1`.  
**Сложность:** базовая

### Задача 3. Подсчёт вхождений

**Вход:** массив из \(n\) целых чисел и число \(x\).  
**Выход:** количество элементов, равных \(x\).  
**Сложность:** базовая

### Задача 4. Все индексы элемента

**Вход:** массив из \(n\) целых чисел и число \(x\).  
**Выход:** все индексы элементов, равных \(x\), в порядке возрастания.  
**Сложность:** базовая

### Задача 5. Сумма элементов на чётных позициях

**Вход:** массив из \(n\) целых чисел.  
**Выход:** сумма элементов с чётными индексами (0, 2, 4, …).  
**Сложность:** базовая

### Задача 6. Элементы больше среднего

**Вход:** массив из \(n\) целых чисел.  
**Выход:** количество элементов, строго больших среднего арифметического всех элементов. Гарантируется, что среднее — целое число (сумма делится на \(n\)).  
**Сложность:** базовая

### Задача 7. Второй максимум

**Вход:** массив из \(n\) целых чисел. Все элементы различны.  
**Выход:** второй по величине элемент массива.  
**Сложность:** базовая

### Задача 8. Фильтрация по знаку

**Вход:** массив из \(n\) целых чисел.  
**Выход:** два массива — из положительных и из отрицательных элементов, в исходном порядке. Нули не включать ни в один.  
**Сложность:** базовая

### Задача 9. Проверка отсортированности

**Вход:** массив из \(n\) целых чисел.  
**Выход:** `YES`, если массив неубывающий; `NO` иначе.  
**Сложность:** базовая

### Задача 10. Поиск элемента с условием

**Вход:** массив из \(n\) целых чисел и число \(k\).  
**Выход:** индекс последнего элемента, кратного \(k\). Если такого нет — вывести `-1`.  
**Ограничения:** \(k \ne 0\).  
**Сложность:** базовая

### Задача 11. Ближайший к среднему

**Вход:** массив из \(n\) целых чисел.  
**Выход:** элемент массива, ближайший к среднему арифметическому. Если несколько — вывести первый по индексу.  
**Ограничения:** среднее может быть дробным.  
**Сложность:** средняя

### Задача 12. Пара с заданной суммой

**Вход:** массив из \(n\) целых чисел и число \(s\).  
**Выход:** индексы \(i < j\), для которых \(a_i + a_j = s\). Если пар несколько — вывести пару с наименьшим \(i\), а при равенстве — с наименьшим \(j\). Если пары нет — вывести `-1 -1`.  
**Сложность:** средняя

## 2. Сортировка и упорядочивание (задачи 13–24)

### Задача 13. Сортировка выбором

**Вход:** массив из \(n\) целых чисел.  
**Выход:** массив, отсортированный по неубыванию.  
**Требование:** реализовать сортировку выбором вручную, без использования встроенных функций сортировки.  
**Сложность:** базовая

### Задача 14. Сортировка вставками

**Вход:** массив из \(n\) целых чисел.  
**Выход:** массив, отсортированный по невозрастанию.  
**Требование:** реализовать сортировку вставками вручную.  
**Сложность:** базовая

### Задача 15. Пузырьковая сортировка с подсчётом обменов

**Вход:** массив из \(n\) целых чисел.  
**Выход:** отсортированный массив и количество обменов, выполненных в процессе пузырьковой сортировки.  
**Требование:** реализовать пузырьковую сортировку с досрочным выходом, если массив уже отсортирован.  
**Сложность:** базовая

### Задача 16. Сортировка по модулю

**Вход:** массив из \(n\) целых чисел.  
**Выход:** массив, отсортированный по неубыванию модуля элементов. При равных модулях первым идёт отрицательный элемент.  
**Сложность:** средняя

### Задача 17. Сортировка по сумме цифр

**Вход:** массив из \(n\) неотрицательных целых чисел.  
**Выход:** массив, отсортированный по возрастанию суммы цифр каждого числа. При равных суммах — сохранить исходный порядок.  
**Сложность:** средняя

### Задача 18. Сортировка только чётных

**Вход:** массив из \(n\) целых чисел.  
**Выход:** тот же массив, в котором все чётные элементы отсортированы по неубыванию, а нечётные остались на своих местах.  
**Сложность:** средняя

### Задача 19. Объединение двух отсортированных массивов

**Вход:** два массива, каждый отсортирован по неубыванию; размеры \(n\) и \(m\).  
**Выход:** один отсортированный массив — результат слияния.  
**Требование:** \(O(n + m)\).  
**Сложность:** средняя

### Задача 20. Сортировка подсчётом

**Вход:** массив из \(n\) целых чисел.  
**Выход:** массив, отсортированный по неубыванию.  
**Требование:** реализовать сортировку подсчётом.  
**Сложность:** средняя

### Задача 21. K-й наименьший элемент

**Вход:** массив из \(n\) целых чисел и число \(k\) (\(1 \le k \le n\)).  
**Выход:** \(k\)-й наименьший элемент массива.  
**Требование:** отсортировать массив и взять элемент с индексом \(k - 1\).  
**Сложность:** базовая

### Задача 22. Сортировка по частоте

**Вход:** массив из \(n\) целых чисел.  
**Выход:** массив, отсортированный по убыванию частоты встречаемости элементов. При равных частотах — по возрастанию значения.  
**Сложность:** средняя

### Задача 23. Проверка анаграммы массивов

**Вход:** два массива одинаковой длины \(n\).  
**Выход:** `YES`, если один массив является перестановкой другого; `NO` иначе.  
**Сложность:** средняя

### Задача 24. Чётно-нечётная сортировка

**Вход:** массив из \(n\) целых чисел.  
**Выход:** массив, в котором все чётные элементы отсортированы по возрастанию и идут первыми, а нечётные отсортированы по убыванию и идут после.  
**Сложность:** средняя

## 3. Арифметика и статистика массивов (задачи 25–36)

### Задача 25. Сумма элементов

**Вход:** массив из \(n\) целых чисел.  
**Выход:** сумма всех элементов.  
**Сложность:** базовая

### Задача 26. Произведение элементов

**Вход:** массив из \(n\) целых чисел.  
**Выход:** произведение всех элементов по модулю \(10^9 + 7\).  
**Сложность:** базовая

### Задача 27. Сумма квадратов

**Вход:** массив из \(n\) целых чисел.  
**Выход:** сумма квадратов всех элементов.  
**Сложность:** базовая

### Задача 28. Медиана массива

**Вход:** массив из \(n\) целых чисел.  
**Выход:** медиана массива. При нечётном \(n\) — элемент посередине после сортировки. При чётном \(n\) — среднее арифметическое двух центральных элементов (как число с плавающей точкой).  
**Сложность:** средняя

### Задача 29. Мода массива

**Вход:** массив из \(n\) целых чисел.  
**Выход:** наиболее часто встречающийся элемент. Если несколько — вывести наименьший по значению.  
**Ограничения:** \(1 \le n \le 10^4\).  
**Сложность:** средняя

### Задача 30. Дисперсия

**Вход:** массив из \(n\) целых чисел.  
**Выход:** выборочную дисперсию по формуле.

**Сложность:** средняя

### Задача 31. Скалярное произведение

**Вход:** два массива одинаковой длины \(n\).  
**Выход:** скалярное произведение  
**Сложность:** базовая

### Задача 32. Сумма произведений пар

**Вход:** массив из \(n\) целых чисел.  
**Выход:** сумма произведений всех пар элементов \(a_i * a_j\) для \(i < j\).  
**Требование:** \(O(n)\)
**Сложность:** высокая

### Задача 33. Количество инверсий

**Вход:** массив из \(n\) целых чисел.  
**Выход:** количество пар \((i, j)\) таких, что \(i < j\) и \(a_i > a_j\).  
**Требование:** \(O(n log n)\) (через модификацию сортировки слиянием).  
**Сложность:** высокая

### Задача 34. Максимальная сумма подмассива

**Вход:** массив из \(n\) целых чисел (могут быть отрицательные).  
**Выход:** максимальная сумму непрерывного подмассива.  
**Требование:** \(O(n)\) (алгоритм Кадане).  
**Сложность:** высокая

### Задача 35. Префиксные суммы

**Вход:** массив из \(n\) целых чисел и \(q\) запросов вида \([l, r]\) — диапазон индексов.  
**Выход:** для каждого запроса — сумму элементов с индексами от \(l\) до \(r\) включительно.  
**Требование:** предпосчёт префиксных сумм, затем \(O(1)\) на запрос.  
**Сложность:** средняя

### Задача 36. Бегущая сумма

**Вход:** массив из \(n\) целых чисел.  
**Выход:** массив той же длины, где \(i\)-й элемент равен сумме первых \(i + 1\) элементов исходного массива.  
**Сложность:** базовая

## 4. Преобразование массивов (задачи 37–48)

### Задача 37. Разворот массива

**Вход:** массив из \(n\) целых чисел.  
**Выход:** массив, записанный в обратном порядке.  
**Требование:** выполнить разворот на месте, без создания нового массива.  
**Сложность:** базовая

### Задача 38. Циклический сдвиг влево

**Вход:** массив из \(n\) целых чисел и число \(k\).  
**Выход:** массив, циклически сдвинутый влево на \(k\) позиций.  
**Требование:** \(O(n)\), \(O(1)\) доп. памяти (через тройной разворот).  
**Сложность:** средняя

### Задача 39. Циклический сдвиг вправо

**Вход:** массив из \(n\) целых чисел и число \(k\).  
**Выход:** массив, циклически сдвинутый вправо на \(k\) позиций.  
**Требование:** учесть, что \(k\) может быть больше \(n\).  
**Сложность:** средняя

### Задача 40. Удаление дубликатов

**Вход:** отсортированный по неубыванию массив из \(n\) целых чисел.  
**Выход:** массив без дубликатов, сохраняя порядок.  
**Требование:** \(O(n)\), модификация исходного массива на месте.  
**Сложность:** средняя

### Задача 41. Удаление элемента

**Вход:** массив из \(n\) целых чисел и число \(x\).  
**Выход:** массив, из которого удалены все вхождения \(x\).  
**Сложность:** базовая

### Задача 42. Вставка элемента в отсортированный массив

**Вход:** отсортированный по неубыванию массив из \(n\) целых чисел и число \(x\).  
**Выход:** массив длины \(n + 1\), в который \(x\) вставлен на правильную позицию.  
**Требование:** использовать бинарный поиск для нахождения позиции.  
**Сложность:** средняя

### Задача 43. Перемещение нулей в конец

**Вход:** массив из \(n\) целых чисел.  
**Выход:** тот же массив, в котором все нули перемещены в конец, порядок остальных элементов сохранён.  
**Требование:** модификация на месте.  
**Сложность:** средняя

### Задача 44. Чередование знаков

**Вход:** массив из \(n\) целых чисел, содержащий равное число положительных и отрицательных элементов (нулей нет).  
**Выход:** массив, в котором положительные и отрицательные элементы чередуются, начиная с положительного. Относительный порядок внутри положительных и отрицательных сохранить.  
**Сложность:** средняя

### Задача 45. Разбиение по опорному элементу

**Вход:** массив из \(n\) целых чисел и опорное значение \(p\).  
**Выход:** массив, переставленный так, что сначала идут все элементы \(< p\), затем \(= p\), затем \(> p\). Относительный порядок внутри групп не важен.  
**Требование:** \(O(n)\), \(O(1)\) доп. памяти.  
**Сложность:** средняя

### Задача 46. Сжатие диапазона

**Вход:** массив из \(n\) целых чисел.  
**Выход:** массив той же длины, где каждый элемент заменён его рангом — номером в отсортированном порядке без дубликатов (начиная с 0).  
**Пример:** `[100, 50, 100, 300]` → `[1, 0, 1, 2]`.  
**Сложность:** высокая

### Задача 47. Поворот массива на 90 градусов

**Вход:** двумерный массив \(n x m\).  
**Выход:** массив \(m x n\), полученный поворотом на 90 градусов по часовой стрелке.  
**Сложность:** средняя

### Задача 48. Транспонирование матрицы

**Вход:** квадратная матрица \(n x n\).  
**Выход:** транспонированная матрица.  
**Требование:** транспонирование на месте, без создания нового массива.  
**Сложность:** средняя

## 5. Двумерные массивы и матрицы (задачи 49–60)

### Задача 49. Сумма строк матрицы

**Вход:** матрица \(n x m\) из целых чисел.  
**Выход:** массив из \(n\) элементов — сумм строк матрицы.  
**Сложность:** базовая

### Задача 50. Сумма столбцов матрицы

**Вход:** матрица \(n x m\) из целых чисел.  
**Выход:** массив из \(m\) элементов — сумм столбцов матрицы.  
**Сложность:** базовая

### Задача 51. Максимум в каждой строке

**Вход:** матрица \(n x m\) из целых чисел.  
**Выход:** массив из \(n\) элементов — максимальных значений в каждой строке.  
**Сложность:** базовая

### Задача 52. Минимум в каждом столбце

**Вход:** матрица \(n x m\) из целых чисел.  
**Выход:** массив из \(m\) элементов — минимальных значений в каждом столбце.  
**Сложность:** базовая

### Задача 53. Седловые точки

**Вход:** матрица \(n x m\) из целых чисел.  
**Выход:** все седловые точки — элементы, одновременно минимальные в своей строке и максимальные в своём столбце. Вывести в формате `(индекс_строки, индекс_столбца, значение)`.  
**Сложность:** средняя

### Задача 54. Сумма элементов на главной диагонали

**Вход:** квадратная матрица \(n x n\).  
**Выход:** сумма элементов на главной диагонали.  
**Сложность:** базовая

### Задача 55. Сумма элементов на побочной диагонали

**Вход:** квадратная матрица \(n x n\).  
**Выход:** сумма элементов на побочной диагонали (от правого верхнего угла к левому нижнему).  
**Сложность:** базовая

### Задача 56. Умножение матриц

**Вход:** матрица \(A\) размера \(n x m\) и матрица \(B\) размера \(m x k\).  
**Выход:** матрица \(C = A x B\) размера \(n x k\).  
**Требование:** \(O(n x m x k)\) - по времени, \(O(n x k)\) - по памяти.
**Сложность:** средняя

### Задача 57. Спиральный обход матрицы

**Вход:** матрица \(n x m\) из целых чисел.  
**Выход:** элементы матрицы, обойдённые по спирали от левого верхнего угла по часовой стрелке.  
**Сложность:** средняя

### Задача 58. Заполнение матрицы змейкой

**Вход:** числа \(n\) и \(m\).  
**Выход:** матрица \(n x m\), заполненная числами от 1 до \(n x m\) змейкой по строкам: первая строка слева направо, вторая — справа налево и т. д.  
**Сложность:** средняя

### Задача 59. Определитель матрицы 3×3

**Вход:** матрица \(3 x 3\) из целых чисел.  
**Выход:** определитель матрицы.  
**Сложность:** средняя

### Задача 60. Острова из единиц

**Вход:** бинарная матрица \(n x m\), состоящая из 0 и 1.  
**Выход:** количество «островов» — групп связанных единиц (связь по горизонтали и вертикали, не по диагонали).  
**Требование:** поиск в глубину (DFS) или в ширину (BFS).  
**Сложность:** высокая

## Требования к оформлению решений

1. Каждое решение — отдельный файл/package с именем `task_<номер>`).
2. В начале файла — комментарий с номером и формулировкой задачи.
3. Ввод-вывод через стандартные потоки.
4. Код должен компилироваться и проходить тесты с указанными ограничениями.
5. Для задач с указанной асимптотической сложностью — соответствие обязательно.
6. Наличие `md` файла с расчетом асимптотики.
