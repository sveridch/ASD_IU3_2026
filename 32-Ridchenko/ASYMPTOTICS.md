## Общая модель оценки

В качестве основной метрики используется `n` — количество элементов во входном массиве.
Согласно условиям задач, `1 < n < 100000`. Все вычисления производятся с типом данных `int`.
Операции сравнения, сложения и присваивания для `int` принимаются за элементарные действия с постоянным временем выполнения `O(1)`.
При оценке памяти учитываются только структуры данных, создаваемые самим алгоритмом (массивы, списки). Накладные расходы JVM и буферы ввода-вывода не учитываются.

## Разбор задач

### Задача 1. Максимум и минимум
Сложность линейная, потому что мы проходим по массиву ровно один раз. Запускаем цикл `for (int i = 1; i < array.length; i++)`, внутри которого на каждой итерации делаем пару сравнений (`if (array[i] < min)` и `if (array[i] > max)`). Количество итераций напрямую зависит от `n`.
**Время:** `O(n)`.
**Доп. память:** `O(1)` — мы не создаем новых массивов, а храним только переменные `min` и `max`.

### Задача 2. Индекс первого вхождения
Сначала массив считывается с клавиатуры (это `O(n)`). Затем мы запускаем цикл `for (int i = 0; i < array.length; i++)` и внутри проверяем `if (array[i] == x)`. В худшем случае (элемента нет или он в самом конце) цикл отработает `n` раз.
**Время:** `O(n)`.
**Доп. память:** `O(1)` для самого поиска (исходный массив в памяти не учитываем как доп. память алгоритма).

### Задача 3. Подсчёт вхождений
Здесь мы используем цикл `for (int num : array)`. Внутри стоит условие `if (num == x) count++`. Мы проходим по всем элементам от начала до конца, поэтому время работы прямо пропорционально длине массива.
**Время:** `O(n)`.
**Доп. память:** `O(1)` — храним только счетчик.

### Задача 4. Все индексы элемента
Тут мы идем по массиву и при совпадении добавляем индекс в список: `if (array[i] == x) indices.add(i);`. Время работы — линейное. Однако если массив состоит только из иксов, список `indices` вырастет до размера `n`. Поэтому память зависит от входных данных.
**Время:** `O(n)`.
**Доп. память:** `O(n)` в худшем случае для хранения списка индексов.

### Задача 5. Сумма элементов на чётных позициях
Цикл `for (int i = 0; i < array.length; i += 2)` перепрыгивает через один элемент. То есть он делает примерно `n/2` итераций. Поскольку константы в асимптотике отбрасываются, сложность все равно линейная.
**Время:** `O(n)`.
**Доп. память:** `O(1)` — храним только сумму.

### Задача 6. Элементы больше среднего
Здесь два последовательных цикла: первый `for (int num : array) sum += num;` нужен для подсчета суммы, второй `for (int num : array)` — для сравнения. Так как циклы идут друг за другом, а не вложены, их сложность складывается: `O(n) + O(n) = O(n)`.
**Время:** `O(n)`.
**Доп. память:** `O(1)` — храним сумму и счетчик.

### Задача 7. Второй максимум
Идем по массиву один раз: `for (int num : array)`. Внутри условия `if (num > max)` и `else if (num > secondMax)` обновляют значения. Вложенных циклов нет, поэтому время линейно зависит от количества элементов.
**Время:** `O(n)`.
**Доп. память:** `O(1)` — только две переменные для максимумов.

### Задача 8. Фильтрация по знаку
Один цикл `for (int num : array)`. Внутри мы раскладываем числа по спискам: `if (num > 0) posList.add(num);`. Время — линейное. Но в худшем случае (если нет нулей) суммарный размер двух новых списков будет равен `n`, поэтому память линейна.
**Время:** `O(n)`.
**Доп. память:** `O(n)` для хранения двух новых списков.

### Задача 9. Проверка отсортированности
Цикл `for (int i = 0; i < array.length - 1; i++)` сравнивает соседние элементы: `if (array[i] > array[i + 1])`. В лучшем случае (если массив сломан в начале) мы выйдем сразу. В худшем (если массив отсортирован) пройдем все `n-1` элементов.
**Время:** `O(n)`.
**Доп. память:** `O(1)`.

### Задача 10. Поиск элемента с условием
Мы идем с конца массива: `for (int i = array.length - 1; i >= 0; i--)`. Внутри проверяем `if (array[i] % k == 0) return i;`. В худшем случае (если кратных нет) мы проверим все `n` элементов.
**Время:** `O(n)`.
**Доп. память:** `O(1)`.

### Задача 11. Ближайший к среднему
Сначала мы одним циклом считаем сумму, а потом вторым ищем ближайший элемент: `double diff = Math.abs(array[i] - avg);`. Два последовательных прохода дают суммарное линейное время.
**Время:** `O(n)`.
**Доп. память:** `O(1)`.

### Задача 12. Пара с заданной суммой
Здесь используется вложенный цикл: `for (int i = 0; ...)` и внутри него `for (int j = i + 1; ...)`. Для каждого элемента мы перебираем всех, кто стоит после него. Количество проверок примерно `n * (n-1) / 2`, что дает квадратичную зависимость.
**Время:** `O(n²)`.
**Доп. память:** `O(1)`.

### Задача 13. Сортировка выбором
Внешний цикл `for (int i = 0; i < result.length - 1; i++)` и внутренний цикл поиска минимума `for (int j = i + 1; j < result.length; j++)`. Это классическая квадратичная сортировка, количество сравнений примерно `n²/2`. Обмен элементов `int temp = result[minIndex];` выполняется на месте.
**Время:** `O(n²)`.
**Доп. память:** `O(1)`.

### Задача 28. Медиана массива
Главная операция здесь — это сортировка. Мы вызываем наш собственный метод `SelectionSort.sort(array)`, который имеет квадратичную сложность. После сортировки мы просто берем центральный элемент или считаем среднее двух центральных. Это занимает константное время. Поэтому общая сложность определяется сортировкой.

Сначала мы сортируем массив:
int[] sortedArray = SelectionSort.sort(array);

Затем проверяем четность и находим медиану:
if (n % 2 != 0) {
    return sortedArray[n / 2];
} else {
    int mid1 = sortedArray[n / 2 - 1];
    int mid2 = sortedArray[n / 2];
    return (mid1 + mid2) / 2.0;
}

**Время:** `O(n²)` из-за сортировки.
**Доп. память:** `O(n)` — так как метод `sort` создает копию исходного массива.

### Задача 33. Количество инверсий
Используется модифицированная сортировка слиянием. Массив рекурсивно делится пополам (это дает `log n` уровней). На каждом уровне происходит слияние, которое занимает линейное время `O(n)`. При слиянии мы считаем инверсии: если элемент из правой половины меньше элемента из левой, то он образует инверсии со всеми оставшимися элементами левой половины. Итого получаем `O(n log n)`.

Рекурсивный вызов для левой и правой части:
int mid = left + (right - left) / 2;
count += mergeSortAndCount(array, left, mid);
count += mergeSortAndCount(array, mid + 1, right);

Подсчет инверсий при слиянии:
if (leftArray[i] <= rightArray[j]) {
    array[k++] = leftArray[i++];
} else {
    array[k++] = rightArray[j++];
    inversions += (leftArray.length - i);
}

**Время:** `O(n log n)`.
**Доп. память:** `O(n)` — для временных массивов при слиянии.
