# Отчет

## Задача 8. Фильтрация по знаку

Разделить массив на два массива: из положительных и из отрицательных элементов. Нули не включать.

### Идея решения

Создаются два пустых списка: для положительных и отрицательных чисел.
Массив просматривается один раз.
Если число больше нуля — добавляется в первый список.
Если меньше нуля — во второй.

### Асимптотика

Один цикл `for (int num : array)`. Внутри мы раскладываем числа по спискам: `if (num > 0) posList.add(num);`. Время — линейное. Но в худшем случае (если нет нулей) суммарный размер двух новых списков будет равен `n`, поэтому память линейна.
**Время:** `O(n)`.
**Доп. память:** `O(n)` для хранения двух новых списков.

### Проверки

- `-1 2 0 -3 4` → положительные: `2 4`, отрицательные: `-1 -3`.
- `1 2 3` → положительные: `1 2 3`, отрицательные: пусто.
- `-1 -2 -3` → положительные: пусто, отрицательные: `-1 -2 -3`.
- `0 0 0` → оба списка пусты.
- `5` → положительные: `5`, отрицательные: пусто.
