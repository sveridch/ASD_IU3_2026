# Отчет

## Задача 5. Сумма элементов на чётных позициях

Найти сумму элементов массива, стоящих на чётных индексах (0, 2, 4, ...).

### Идея решения

Заводится переменная суммы, равная нулю.
Цикл проходит по массиву с шагом 2, начиная с индекса 0.
На каждой итерации значение элемента прибавляется к сумме.

### Асимптотика

Цикл `for (int i = 0; i < array.length; i += 2)` перепрыгивает через один элемент. То есть он делает примерно `n/2` итераций. Поскольку константы в асимптотике отбрасываются, сложность все равно линейная.
**Время:** `O(n)`.
**Доп. память:** `O(1)` — храним только сумму.

### Проверки

- `5 2 9 1 7` → 21: индексы 0, 2, 4 (5+9+7).
- `1 2 3 4` → 4: индексы 0, 2 (1+3).
- `10` → 10: один элемент.
- `-1 -2 -3` → -4: отрицательные числа (-1 + -3).
- `0 0 0 0` → 0: все нули.
