# Отчет

## Задача 4. Все индексы элемента

Вывести все индексы элементов массива, равных заданному числу x, в порядке возрастания.

### Идея решения

Создается пустой список для хранения индексов.
Массив просматривается слева направо с помощью цикла с индексом i.
Если элемент равен x, его индекс i добавляется в список.
В конце список выводится.

### Асимптотика

Тут мы идем по массиву и при совпадении добавляем индекс в список: `if (array[i] == x) indices.add(i);`. Время работы — линейное. Однако если массив состоит только из иксов, список `indices` вырастет до размера `n`. Поэтому память зависит от входных данных.
**Время:** `O(n)`.
**Доп. память:** `O(n)` в худшем случае для хранения списка индексов.

### Проверки

- `5 2 9 5 7 5`, x = 5 → `0 3 5`: три совпадения.
- `5 2 9 5 7 5`, x = 10 → пустой список: число отсутствует.
- `1 1 1 1`, x = 1 → `0 1 2 3`: все элементы равны.
- `-2 -2`, x = -2 → `0 1`: отрицательные числа.
- `42`, x = 42 → `0`: один элемент.
