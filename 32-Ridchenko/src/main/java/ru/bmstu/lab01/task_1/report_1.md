# Отчет

## Задача 1. Максимум и минимум

Найти минимальный и максимальный элементы массива целых чисел.

### Идея решения

Первое число принимается за начальный минимум и максимум.
Каждое следующее число сравнивается с текущими значениями.
При необходимости минимум или максимум обновляется.

Числа обрабатываются последовательно, без хранения всего массива.

### Асимптотика

Сложность линейная, потому что мы проходим по массиву ровно один раз. Запускаем цикл `for (int i = 1; i < array.length; i++)`, внутри которого на каждой итерации делаем пару сравнений (`if (array[i] < min)` и `if (array[i] > max)`). Количество итераций напрямую зависит от `n`.
**Время:** `O(n)`.
**Доп. память:** `O(1)` — мы не создаем новых массивов, а храним только переменные `min` и `max`.

### Проверки

- `7 -2 10 0 4` → `-2 10`: числа разных знаков и ноль.
- `5 9 3` → `3 9`: только положительные числа.
- `-5 -9 -2` → `-9 -2`: только отрицательные числа.
- `4 4 4` → `4 4`: одинаковые элементы.
- `-2147483648 2147483647` → `-2147483648 2147483647`: крайние значения int.
