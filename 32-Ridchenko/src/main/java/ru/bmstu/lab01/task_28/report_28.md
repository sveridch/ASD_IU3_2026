# Отчет

## Задача 28. Медиана массива

Найти медиану массива. При нечётном n — центральный элемент после сортировки. При чётном n — среднее двух центральных.

### Идея решения

Массив сортируется методом выбора (из Задачи 13).
Вычисляется индекс середины.
Если n нечетное, возвращается элемент по индексу n/2.
Если n четное, берутся два центральных элемента, и вычисляется их среднее арифметическое как число с плавающей точкой (деление на 2.0).

### Асимптотика

Главная операция здесь — это сортировка. Мы вызываем наш собственный метод `SelectionSort.sort(array)`, который имеет квадратичную сложность. После сортировки мы просто берем центральный элемент или считаем среднее двух центральных. Это занимает константное время. Поэтому общая сложность определяется сортировкой.

Сначала мы сортируем массив:
int[] sortedArray = SelectionSort.sort(array);

Затем проверяем четность и находим медиану:
if (n % 2 != 0) {
    return sortedArray[n / 2];
} else {
    int mid1 = sortedArray[n / 2 - 1];
    int mid2 = sortedArray[n / 2];
    return (mid1 + mid2) / 2.0;
}

**Время:** `O(n²)` из-за сортировки.
**Доп. память:** `O(n)` — так как метод `sort` создает копию исходного массива.

### Проверки

- `5 2 9 1 7` → 5.0: нечетная длина, центральный элемент 5.
- `5 2 6 1` → 3.5: четная длина, центральные 2 и 5, среднее 3.5.
- `42` → 42.0: один элемент.
- `1 2 3 4` → 2.5: четная длина, центральные 2 и 3.
- `-5 -1 -9` → -5.0: нечетная длина, отрицательные числа.
