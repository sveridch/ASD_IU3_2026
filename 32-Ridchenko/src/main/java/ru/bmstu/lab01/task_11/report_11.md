# Отчет

## Задача 11. Ближайший к среднему

Найти элемент массива, ближайший к среднему арифметическому. Если несколько — вывести первый по индексу.

### Идея решения

Первый цикл вычисляет сумму элементов.
Среднее арифметическое вычисляется как double (может быть дробным).
Второй цикл проходит по массиву и для каждого элемента считает модуль разности со средним.
Если разность меньше текущей минимальной, запоминается элемент и обновляется минимум.
Строгое неравенство гарантирует, что при равенстве останется первый по индексу.

### Асимптотика

Сначала мы одним циклом считаем сумму, а потом вторым ищем ближайший элемент: `double diff = Math.abs(array[i] - avg);`. Два последовательных прохода дают суммарное линейное время.
**Время:** `O(n)`.
**Доп. память:** `O(1)`.

### Проверки

- `5 2 9 1 7 6` → 5: среднее 5.0, ближайшие 5 и 7, берем первый — 5.
- `1 2 3` → 2: среднее 2.0, ближайший — 2.
- `10 20` → 10: среднее 15.0, разница 5 у обоих, берем первый — 10.
- `-5 -2 -8` → -5: среднее -5.0, ближайший — -5.
- `42` → 42: один элемент.
