# Отчет

## Задача 7. Второй максимум

Найти второй по величине элемент массива. Все элементы различны.

### Идея решения

Заводятся две переменные: для максимума и для второго максимума.
Обе инициализируются минимально возможным значением int.
При проходе по массиву, если число больше текущего максимума, то старый максимум становится вторым максимумом, а новое число — максимумом.
Иначе, если число больше второго максимума, оно становится вторым максимумом.

### Асимптотика

Идем по массиву один раз: `for (int num : array)`. Внутри условия `if (num > max)` и `else if (num > secondMax)` обновляют значения. Вложенных циклов нет, поэтому время линейно зависит от количества элементов.
**Время:** `O(n)`.
**Доп. память:** `O(1)` — только две переменные для максимумов.

### Проверки

- `5 2 9 1 7` → 7: максимум 9, второй 7.
- `10 20 30` → 20: максимум 30, второй 20.
- `-5 -1 -9` → -5: максимум -1, второй -5.
- `1 2` → 1: минимум два элемента.
- `100 50 75` → 75: максимум 100, второй 75.
