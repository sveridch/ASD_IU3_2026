# Отчет

## Задача 33. Количество инверсий

Найти количество пар (i, j), таких что i < j и a[i] > a[j]. Требуется O(n log n).

### Идея решения

Используется модифицированная сортировка слиянием.
Массив рекурсивно делится на две половины.
Инверсии считаются в левой половине, в правой половине и при слиянии.
При слиянии, если элемент из правой половины меньше элемента из левой, то он образует инверсии со всеми оставшимися элементами левой половины.
Количество таких инверсий равно длине оставшейся части левого массива.

### Асимптотика

Используется модифицированная сортировка слиянием. Массив рекурсивно делится пополам (это дает `log n` уровней). На каждом уровне происходит слияние, которое занимает линейное время `O(n)`. При слиянии мы считаем инверсии: если элемент из правой половины меньше элемента из левой, то он образует инверсии со всеми оставшимися элементами левой половины. Итого получаем `O(n log n)`.

Рекурсивный вызов для левой и правой части:
int mid = left + (right - left) / 2;
count += mergeSortAndCount(array, left, mid);
count += mergeSortAndCount(array, mid + 1, right);

Подсчет инверсий при слиянии:
if (leftArray[i] <= rightArray[j]) {
    array[k++] = leftArray[i++];
} else {
    array[k++] = rightArray[j++];
    inversions += (leftArray.length - i);
}

**Время:** `O(n log n)`.
**Доп. память:** `O(n)` — для временных массивов при слиянии.

### Проверки

- `5 2 9 1 7` → 5: инверсии (5,2), (5,1), (2,1), (9,1), (9,7).
- `1 2 3 4 5` → 0: отсортированный массив.
- `5 4 3 2 1` → 10: обратный порядок, n*(n-1)/2.
- пустой массив → 0.
- `1` → 0: один элемент.
