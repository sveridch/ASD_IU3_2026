# Отчет

## Задача 41. Удаление элемента

Удалить все вхождения заданного числа x из массива.

### Идея решения

Создается пустой список.
Массив просматривается один раз.
Если элемент не равен x, он добавляется в список.
В конце список превращается в массив и выводится.

### Асимптотика

Мы проходим по исходному массиву один раз, проверяя каждое число. Если оно не равно `x`, мы добавляем его в новый список. В худшем случае (если `x` в массиве нет) размер нового списка будет равен `n`. Время работы линейно зависит от длины исходного массива.

Проход по массиву и проверка условия:
```java
for (int num : array) {
    if (num != x) {
        resultList.add(num);
    }
}
Время: O(n).
Дополнительная память: O(n) — так как мы создаем новый массив (список) для хранения результата.

### Проверки

- `5 2 9 5 7 5`, x = 5 → `2 9 7`: удалены все пятерки.
- `5 2 9 1 7`, x = 10 → `5 2 9 1 7`: числа 10 нет, массив не изменился.
- `5 5 5 5`, x = 5 → пустой массив: удалены все элементы.
- пустой массив → пустой массив.
- `-2 -2 3`, x = -2 → `3`: отрицательные числа.
