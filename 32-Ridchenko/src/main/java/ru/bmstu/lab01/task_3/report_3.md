# Отчет

## Задача 3. Подсчёт вхождений

Найти количество элементов массива, равных заданному числу x.

### Идея решения

Заводится счетчик, изначально равный нулю.
Массив просматривается один раз.
При каждом совпадении счетчик увеличивается на единицу.
В конце выводится значение счетчика.

### Асимптотика

Здесь мы используем цикл `for (int num : array)`. Внутри стоит условие `if (num == x) count++`. Мы проходим по всем элементам от начала до конца, поэтому время работы прямо пропорционально длине массива.
**Время:** `O(n)`.
**Доп. память:** `O(1)` — храним только счетчик.


### Проверки

- `5 2 5 1 7`, x = 5 → 2: число встречается дважды.
- `5 2 5 1 7`, x = 10 → 0: число отсутствует.
- `0 0 0 0`, x = 0 → 4: все элементы равны нулю.
- `-1 -1 -1`, x = -1 → 3: отрицательные числа.
- `42`, x = 42 → 1: массив из одного элемента.
