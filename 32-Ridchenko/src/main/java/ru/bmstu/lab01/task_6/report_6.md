# Отчет

## Задача 6. Элементы больше среднего

Найти количество элементов массива, строго больших среднего арифметического.

### Идея решения

Первый цикл проходит по массиву и вычисляет сумму всех элементов.
Среднее арифметическое вычисляется как сумма, деленная на n (по условию делится нацело).
Второй цикл проходит по массиву и сравнивает каждый элемент со средним.
Если элемент строго больше, счетчик увеличивается.

### Асимптотика

Здесь два последовательных цикла: первый `for (int num : array) sum += num;` нужен для подсчета суммы, второй `for (int num : array)` — для сравнения. Так как циклы идут друг за другом, а не вложены, их сложность складывается: `O(n) + O(n) = O(n)`.
**Время:** `O(n)`.
**Доп. память:** `O(1)` — храним сумму и счетчик.

### Проверки

- `5 2 9 1 7 6` → 3: среднее 5, больше 5 это 9, 7, 6.
- `1 2 3` → 1: среднее 2, больше 2 это 3.
- `10 10 10` → 0: все равны среднему.
- `-5 -2 -8` → 1: среднее -5, больше -5 это -2.
- `1` → 0: один элемент, не больше самого себя.
