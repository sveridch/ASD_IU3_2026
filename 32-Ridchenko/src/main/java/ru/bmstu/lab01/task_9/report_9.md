# Отчет

## Задача 9. Проверка отсортированности

Проверить, является ли массив неубывающим. Вывести YES или NO.

### Идея решения

Цикл проходит по массиву, начиная с первого элемента и до предпоследнего.
Сравниваются текущий и следующий элементы.
Если текущий больше следующего, порядок нарушен, выводится NO и цикл прерывается.
Если цикл дошел до конца без нарушений, выводится YES.

### Асимптотика

Цикл `for (int i = 0; i < array.length - 1; i++)` сравнивает соседние элементы: `if (array[i] > array[i + 1])`. В лучшем случае (если массив сломан в начале) мы выйдем сразу. В худшем (если массив отсортирован) пройдем все `n-1` элементов.
**Время:** `O(n)`.
**Доп. память:** `O(1)`.

### Проверки

- `1 2 2 3 5` → YES: неубывающий массив.
- `1 3 2 4 5` → NO: нарушение порядка.
- `5 4 3 2 1` → NO: строго убывающий.
- `7` → YES: один элемент.
- `0 0 0` → YES: все равны.
