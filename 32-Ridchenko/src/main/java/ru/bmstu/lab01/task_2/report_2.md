# Отчет

## Задача 2. Индекс первого вхождения

Найти индекс первого элемента массива, равного заданному числу.
Если такого элемента нет, вывести -1.

### Идея решения

Массив просматривается слева направо.
При первом совпадении сохраняется индекс и поиск завершается.
Если совпадений нет, выводится -1.

Массив хранится в памяти, поскольку число x вводится после элементов.

### Асимптотика

Сначала массив считывается с клавиатуры (это `O(n)`). Затем мы запускаем цикл `for (int i = 0; i < array.length; i++)` и внутри проверяем `if (array[i] == x)`. В худшем случае (элемента нет или он в самом конце) цикл отработает `n` раз.
**Время:** `O(n)`.
**Доп. память:** `O(1)` для самого поиска (исходный массив в памяти не учитываем как доп. память алгоритма).

### Проверки

- `7 3 10 3 4`, x = 3 → 1: первое из нескольких совпадений.
- `2 4 6`, x = 5 → -1: число отсутствует.
- `8 2 5`, x = 8 → 0: совпадение в начале.
- `8 2 5`, x = 5 → 2: совпадение в конце.
- `-7 -3`, x = -3 → 1: отрицательные числа и минимальный размер.
