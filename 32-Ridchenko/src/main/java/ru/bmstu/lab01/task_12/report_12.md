# Отчет

## Задача 12. Пара с заданной суммой

Найти индексы i < j, для которых a[i] + a[j] = s. Если пар несколько — вывести пару с наименьшим i, а при равенстве — с наименьшим j.

### Идея решения

Используется двойной цикл.
Внешний цикл перебирает i от 0 до n-1.
Внутренний цикл перебирает j от i+1 до n-1.
Проверяется сумма a[i] + a[j].
При первом совпадении возвращаются индексы.
Если после обоих циклов пара не найдена, возвращается [-1, -1].

### Асимптотика

Здесь используется вложенный цикл: `for (int i = 0; ...)` и внутри него `for (int j = i + 1; ...)`. Для каждого элемента мы перебираем всех, кто стоит после него. Количество проверок примерно `n * (n-1) / 2`, что дает квадратичную зависимость.
**Время:** `O(n²)`.
**Доп. память:** `O(1)`.

### Проверки

- `1 2 3 4 5`, s = 5 → `0 3`: 1+4=5 (пара с наименьшим i).
- `1 2 3 4 5`, s = 10 → `-1 -1`: пары нет.
- `1 1 1`, s = 2 → `0 1`: первая возможная пара.
- `-5 10 5`, s = 5 → `0 1`: -5+10=5.
- `7 2`, s = 9 → `0 1`: минимальный размер массива.
